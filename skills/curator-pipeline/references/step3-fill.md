# Step 3 — 分章深度填充

> 目标：按 Step 2 的章节结构 + P 级标记，逐章生成内容；严格按白/黑名单选来源；每章完成做自检三连。
> **失败要点**：编造来源 / 用黑名单内容 / 一键直出不自检。

## 0. 读规范

每次都重读 `/root/xhs-shop/memory/CURATOR_STYLE.md` 的"来源白名单 / 黑名单"段。

## 1. 单章执行循环

对蓝图里的每个章节 N：

### 1.1 准备查询

按章节内 ★ 的 P 级，写明确的搜索查询：

- **P0**：3 个查询（起源 / 原理 / 实证）。例：
  - "卡片盒笔记法 起源 卢曼 历史"
  - "Zettelkasten 工作原理 论文"
  - "卡片盒笔记法 实证案例 高产作家"
- **P1**：1 个查询，瞄准权威来源
- **P2**：跳过搜索

### 1.2 执行搜索 + 筛选

工具优先级：WebSearch → web-access（需要登录/动态页时） → smart-fetch

筛选规则：
- 命中黑名单（百度百科、CSDN 营销稿、内容农场）→ 丢弃
- 双源验证：补充信息必须 ≥2 个独立来源相互印证才能采用
- 双源失败 → 标该信息为"未深挖"，不写入

### 1.3 失败处理

- P0 某层完全无果 → 标"未深挖（起源层缺失）"，不能伪造来源；Step 4 终审时强提醒
- 搜索结果全是黑名单 → 报告并询问用户"允许使用？还是放弃此 ★？"。**禁止悄悄使用**

### 1.4 写章节正文

把搜索所得 + 原文素材，按蓝图里的"风格基调"融合，写成章节正文。要求：
- 所有补充信息标来源（脚注或行内链接），写入 `references.md`
- 保留原文核心脉络，补充内容做血肉不抢戏
- 行动指南 / 清单 / 检查表 / 对比表（如有）放在章节末

### 1.5 自检三连（必答）

每章正文写完，AI 必须在对话里显式回答以下 3 个问题（不答完不算完成本章）：

```
🔍 章节 N 自检
1. "如果买家读完这章感觉被骗，最可能是哪里？"
   答: <具体到段落或论点>
2. "这章独立看，是不是一篇可以引流的小红书笔记 hook？"
   答: <是/否，理由>
3. "这章的来源信息是否经得起买家追问？"
   答: <是/否，列出最弱的 1-2 个来源>
```

如果任一项答"否"或"心里没底" → 修改章节，重做自检。

### 1.6 确认门（严格模式）/ 整体确认（fast 模式）

**严格模式**：每章独立等用户确认。"章节 N 完成（含自检三连）。继续章节 N+1 吗？"

**Fast 模式**：所有章节连写，整体跑完一次性给用户看；只在所有章节自检三连都过了之后整体确认。

## 2. 全部章节完成后

写入 meta.json：
```json
{
  "step_progress": { "current_step": 4, "completed_steps": [1,2,3] }
}
```

把所有章节内容追加到 `products/<slug>/curation.md`。
所有补充来源累计写到 `products/<slug>/references.md`。
